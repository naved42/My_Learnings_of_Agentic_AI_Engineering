# Day 7

This folder covers conditional workflows in agentic AI.

## Files

- `conditional_workflow.py` — demonstrates a simple conditional routing system using Python.

## Concept

The script checks the user message and routes it to one of three actions:

- `refund`
- `support`
- `general`

This is a basic example of how an agent can decide which path to take based on user intent.

## Run it

```bash
python conditional_workflow.py
```
